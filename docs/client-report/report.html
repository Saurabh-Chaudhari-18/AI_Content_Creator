What is done

Features you can use today

Writing posts

  • Post Studio: write once, or give each platform its own wording
  • Live Instagram, Facebook and LinkedIn previews as you type
  • Character-limit rings per platform (ready, near limit, over)
  • Hashtags and call-to-action button
  • 16 Smart Templates with fill-in blanks, by industry
  • Photos and videos: upload, reorder, remove; location data removed

Approval

  • Send for approval — the post locks so the approver sees exactly what will go out
  • Approve, request changes with a comment, or withdraw to edit
  • Approval seal: a fingerprint of the approved content
  • Any edit after approval sends it back for approval
  • Approval record with every step, kept permanently
  • Printable approval certificate

Publishing

  • Post right now, or schedule for a date and time
  • Pre-publish check for each account
  • Live status per account: posted, or a clear reason it didn't
  • Try again for failures — never posts twice
  • Content calendar of scheduled and published posts
  • Account health with warnings before access expires

Workspace and team

  • Sign up, sign in, stay signed in across reloads
  • Owner, admin and member roles
  • Self-approval rule for one-person businesses
  • Brands with industry, audience, tone, language and logo
  • 30-day usage summary

Design

  • The owner's palette: obsidian, indigo, amber for waiting, emerald for done
  • Dark by default; light and "match my device" saved per user
  • Icon-rail navigation; bottom bar on phones
  • Each brand shown in its own colour

Trust and security

  • Each customer's data strictly separated
  • Social media access keys encrypted, never shown
  • Full audit trail of who did what, and when
  • Login attempt limits; secure sessions

The full journey, end to end

Run on 7 November with the publishing worker active and test accounts for each platform. The demo video shows exactly this.

1Sign in

Owner of the demo agency signs in; Home loads with live counts.

2Write

New post for a brand: title, caption, hashtags, button text, photo. Previews update live.

3Send for approval

The post locks and is sealed with its content fingerprint.

4Approve

Approved; the seal is stamped on the approval record.

5Publish

Posted to Instagram, Facebook and LinkedIn test accounts within seconds; certificate available.

Demo video — OmniPost-Demo-Tour.mp4

1 minute 51 seconds, sent with this report. Captions explain each step: sign in → Home → Posts → new post with live previews → photo → approval → publishing → certificate.

About the demo data. Brands, posts and accounts are sample data. Publishing goes to test accounts that simulate each platform — nothing reaches real social media until the client's Meta and LinkedIn apps are connected.

What is in progress and what comes next

Finishing Phase 1, then Phase 2

In progress

  • Live Facebook and Instagram publishing. Needs the client's Meta developer app, business verification and a test Page with an Instagram business account.
  • LinkedIn connect. Added once the client's LinkedIn developer app is approved; until then LinkedIn runs on test accounts.
  • Polish and testing. Automated browser tests for the main journey, an accessibility pass, and a phone-layout pass on every screen.
  • One-step installation for new developers and review machines.

Next — to finish Phase 1

  • Hosted review environment so stakeholders can try OmniPost from their own browsers
  • End-to-end test pass there, a demo script and a known-limitations list
  • Phase 1 review and sign-off

Phase 2 and later

  • AI content: captions, hashtags, calls to action and post ideas from each brand's profile; AI images. AI output always goes through the same approval step.
  • Richer publishing: Instagram carousels, Reels and Stories; LinkedIn images; video.
  • Team: email invitations, roles and removal, password reset.
  • Workflow: multi-level approvals, bulk scheduling, comments.
  • Insights: post performance and analytics.
  • Billing: plans and credits, built on the usage tracking already in place.

Known limits today

  • Instagram: one photo per post; LinkedIn: text only for now
  • Meta access lasts about 60 days; OmniPost warns 7 days before
  • No AI generation yet — Smart Templates and manual writing

How it is built

Solid foundations for the next phases

Technology

  • Web app: React and TypeScript
  • Backend: Python FastAPI
  • Database: PostgreSQL 16
  • Background publishing: Celery workers with Redis
  • Media: secure storage with time-limited links

Reliability

  • Scheduled posts are kept in the database and survive restarts
  • Never publishes twice; unclear outcomes go to a person to check
  • Approved content is checked again right before publishing
  • 66 automated tests covering the rules above

Security and records

  • Customers' data strictly separated
  • Social media keys encrypted at rest
  • Short-lived sessions with secure cookies
  • Audit trail of every significant action, kept permanently
Full technical documentation — system design, database, backend features, roadmap and developer setup — is in the project repository's docs folder.
