  Home). Looked at Watermelon UI's real site (dark, lime accent, mono

## Frontend started (code in `frontend/`, not committed yet)

- Stack: **React 19 + TypeScript + Vite 6 + Tailwind 4 + shadcn/ui**,
  TanStack Query, React Router 7. Vite 6 (not 7) because the dev machine
  has Node 20.18 and Vite 7 needs 20.19+.
- **D2 default applied:** React + Vite (the plan said "if no answer by
  Friday, we start with React + Vite"). Still worth confirming with the owner.
- **Look:** the "Chosen direction" (bento, calm colours, plain words) as
  colour tokens, light default + dark mode + "match my device". Switching
  to the Watermelon + Impeccable look later = edit the tokens file only.
- Built: sign-in, register, protected routes, app shell (workspace +
  brand switcher, nav, theme menu, sign out), Home with **live data**
  (counts, needs-attention list with failures first, account health).
- Auth follows the backend's security model: access token in memory only,
  HttpOnly refresh cookie, CSRF header, **single-flight refresh** (refresh
  tokens rotate, so two parallel refreshes would log the user out). Dev
  server proxies `/api` so browser and API share one origin.
- Problem found and fixed: shadcn's first `init` failed half-way and
  installed an unrelated npm package called `cn` and pointed every
  component at it. Removed it, added the real `lib/utils.ts`.
