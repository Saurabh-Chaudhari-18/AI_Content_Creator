# AI Content Creator

B2B social media marketing SaaS — one workspace where a business or agency
manages brand information, creates content (Smart Templates in MVP; AI in
Phase 2), coordinates approvals, and publishes to connected social channels.

| Part | Stack | Status |
|---|---|---|
| [`backend/`](backend/) | FastAPI · PostgreSQL 16 · Celery/Redis · S3 | MVP in progress |
| [`frontend/`](frontend/) | React · TypeScript · Vite · Tailwind · shadcn/ui | MVP in progress |
